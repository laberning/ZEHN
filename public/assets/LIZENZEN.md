# Lizenzen der Grafiken

Die Dateien in `lpc/` stammen aus dem [Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator)
(Liberated Pixel Cup). Sie wurden zugeschnitten; im Spiel werden sie umgefärbt und zu Figuren kombiniert.

Jede Datei steht unter den Lizenzen, die in `CREDITS.csv` für sie angegeben sind (CC0, CC-BY, OGA-BY, CC-BY-SA und/oder GPL).

**Gewählte Lizenz:** Wo ein Teil mehrere Lizenzen zur Auswahl anbietet, nutzen wir es unter CC0, OGA-BY oder CC-BY, sonst unter **CC-BY-SA 3.0** – nie unter GPL.
Die daraus abgeleiteten Grafiken (zugeschnittene Teile, umgefärbte und kombinierte Figuren) geben wir unter derselben Lizenz weiter, bei CC-BY-SA-Teilen also unter CC-BY-SA 3.0.
Die Share-Alike-Pflicht betrifft nur Grafiken; der Code des Spiels steht unter der MIT-Lizenz (`LICENSE` im Projekt).
Die Liste wird von `npm run assets:lpc` erzeugt; im Spiel ist sie unter „Credits“ zu sehen.
